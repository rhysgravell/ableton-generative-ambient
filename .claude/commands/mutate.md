Transform a MIDI file for the Buried Landscapes project.

The user will name a file (generated by /generate or elsewhere) and describe a transform in plain language, e.g. "/mutate slow_chords_G_minor.mid transpose down 2 and humanize" or "/mutate arp.mid reverse".

If the input file isn't found as given, check `/Users/rhysgravell/MIDI/Buried_Landscapes/Claude_MIDI/` (where /generate saves files) before asking the user to clarify the path.

Map their intent to flags and run:

```
python3 midi/mutate_midi.py <input> [--transpose N] [--humanize [AMOUNT]] [--reverse] [--stretch FACTOR] [--velocity-scale FACTOR] [--seed SEED] [--output OUTPUT]
```

Flags:
- `--transpose N` — shift all notes by N semitones (positive or negative)
- `--humanize [AMOUNT]` — add timing + velocity randomness, 0.0–1.0 (default 0.35 if given with no value)
- `--reverse` — reverse note order in time
- `--stretch FACTOR` — time-stretch (2.0 = twice as slow, 0.5 = twice as fast)
- `--velocity-scale FACTOR` — multiply all velocities (e.g. 0.7 to dim, 1.3 to boost)
- `--seed SEED` — random seed, for reproducible humanize
- `--output OUTPUT` — output path (default: `<input>_mutated.mid`, written alongside the input)

Multiple transforms can be stacked in one call. Only pass flags the user actually implied — don't invent transforms they didn't ask for.

After running, tell the user which transforms were applied and where the output file was saved.
